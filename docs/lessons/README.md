# 经验记录

本目录记录本产品**踩过的坑与提炼出的结论**。
规范：`~/.claude/templates/project/LESSONS.md`。

**命名：** `<YYYY-MM-DD>-<kebab-slug>.md`（日期在前，与本机 memory 的命名**故意反向**以便区分）
**组织：** 按日期一文件，**不 append 到单文件**（单文件终会变成没人读的长文）
**索引维护：** 新增时在此表加一行（`new-lesson.mjs` 会自动追加）

---

| 日期 | 分类 | 主题 | 一句话结论 | 状态 |
| --- | --- | --- | --- | --- |

---

## 状态含义

| 状态 | 含义 |
| --- | --- |
| `有效` | 结论仍成立，照做 |
| `已被推翻` | 加横幅、**正文保留**（「曾以为是 X 其实是 Y」本身可复用） |
| `仅历史` | 环境已不存在，保留供追溯 |

## 与其它地方的分工

| 内容 | 去哪 |
| --- | --- |
| **该产品**的技术/领域经验 | **本目录** |
| 工具链 / 配置 / 跨仓经验 | `~/.claude/projects/*/memory/` |
| 过程原始快照 | `docs/session/findings.md`（gitignore） |
| 当时做了什么的记录 | `docs/ops/` |

**判据：换一台机器、换一个 agent，这条经验还成立吗？** 成立 → 本目录。

## 校验

`audit-docs.mjs` 的 D8 检查：索引行数 == 目录 `.md` 数 − 1（减掉本文件）。
